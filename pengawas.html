📖 Tutorial Menyambungkan Google Spreadsheet

  1. Buka Google Sheets (sheets.google.com) dan buat Spreadsheet baru (misal: Rekap SAS IPA Kelas 9).
  2. Klik menu Ekstensi (Extensions) → Apps Script, lalu hapus semua kode bawaan.
  3. Klik tombol di bawah untuk menyalin kode Apps Script, lalu tempel ke editor Apps Script dan simpan (Ctrl+S / Cmd+S):
  4. Klik Terapkan (Deploy) → Deployment baru (New deployment) → pilih jenis Aplikasi Web (Web app).
  5. Atur Jalankan sebagai = Saya (Me) dan Yang memiliki akses = Siapa saja (Anyone) → klik Terapkan (Deploy) dan izinkan akses.
  6. Salin URL Web App yang berakhiran /exec, lalu tempel di kolom URL Web App Google Spreadsheet pada halaman ini dan klik Tes Koneksi.
  7. Jika memakai GitHub Pages: klik Salin Config GitHub lalu tempel ke file data/config.json di repositori GitHub Anda (elsaayuningthiaswahyudi/IPA9SAS) agar seluruh perangkat siswa otomatis terhubung.
